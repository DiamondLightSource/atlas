# b21 App

The aim of this app to provide a science facing UI for the b21 vertical slice project.

## Running Locally

To run this locally:

1.  Start the devcontainer in VSCode
1.  To make sure you have the most up-to-date environment either run `pnpm install` in the container or rebuild the container (via the Ctrl+Shift+P menu in VSCode)
1.  In a terminal in this devcontainer run `turbo dev --filter @atlas/b21`
1.  Navigate to http://localhost:5173/
